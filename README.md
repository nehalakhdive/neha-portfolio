# Neha Lakhdive — Developer Portfolio

Personal portfolio website built with **TanStack Start**, **React**, **TypeScript**, **Tailwind CSS**, and **Vite**.

## Local Development

```sh
npm install
npm run dev
```

## Scripts

- `npm run dev` — Start the Vite + TanStack Start development server
- `npm run build` — Build client, SSR, and Nitro production bundles
- `npm test` — Run Vitest unit tests
- `npm run lint` — Run ESLint
